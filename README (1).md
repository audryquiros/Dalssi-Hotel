# Dalssi Hotel

Proyecto inicial del sistema de gestión hotelera Dalssi.

## Requisitos
- Node.js 20.19+ o 22.12+
- npm

## Ejecutar el frontend

```bash
cd frontend
npm install
npm run dev
```

Vite mostrará la dirección local en la terminal (normalmente `http://localhost:5173`).

## Estructura
- `frontend/`: aplicación React + Vite.
- `AGENTS.md`: reglas de arquitectura, desarrollo y branding.
- `backend/`: reservado para la siguiente etapa (Node.js + Express).

## Nota
Esta entrega contiene la base del frontend y pantallas iniciales de navegación. Todavía no incluye backend ni conexión a MySQL; se implementarán en la etapa correspondiente, respetando el DER aprobado.
